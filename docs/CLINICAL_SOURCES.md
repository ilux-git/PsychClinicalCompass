## Паспорт перед включением в приложение

Для каждого включаемого инструмента/правила нужны: идентификатор и версия; официальный URL; дата проверки и SHA-256 сохранённого документа; применимая популяция и ограничения; раздел/страница источника; точный утверждённый текст; условия использования; медицинский согласующий и дата; проверенные положительный/отрицательный/неполный примеры. Для препарата дополнительно — РУ, статус, редакция инструкции, показания и ограничения; для направления — категория «обязательно/желательно», основание и согласованный маршрут.

Неустановленный источник или неполные данные означают «правило не разрешено к применению», а не отсутствие риска. Положительный пункт 9 PHQ-9 сам по себе не подтверждает непосредственную угрозу жизни.

## Комплект для медицинского согласующего

1. Выбрать версии шкал и предоставить разрешённые тексты/условия использования.
2. Определить клинические кейсы Авиандра из ТЗ с профилями и ожидаемыми действиями врача. Из торгового названия не выводятся показания и назначение.
3. Для каждого шага указать действующую рекомендацию/инструкцию и точное основание.
4. Отдельно согласовать критические критерии, уведомления и резервный маршрут — [B03](BLOCKERS.md).

После согласования: добавить версионированные правила с источниками, различимую безопасность/направления и один полный демонстрационный кейс; проверить, что каждое действие требует врача и не меняет МИС без разрешённого контракта.
