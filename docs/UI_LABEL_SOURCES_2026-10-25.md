# Проверенные наименования для интерфейса · 25.10.2026

Область: расшифровка точного кода, уже полученного из МИС, и русское написание названия в простой исходной строке назначения. Это справочный слой отображения; диагноз, рекомендация, допустимость назначения, регистрация препарата и доза им не определяются. Базы и исходные строки не изменяются.

Использованы первичные официальные PDF, повторно открытые 25.10 через веб-извлечение. Название «текущая действующая редакция» без отдельной реестровой проверки не заявляется. Источники ранее предложены врачом; их использование здесь ограничено наименованиями, новые медицинские правила не включены.

Номера страниц однобазовые, соответствуют P8/P6/P24/P95/P5/P51 веб-извлечения с нулевой базой. Для этих точечных фрагментов выполнен поиск/чтение текста; полного повторного чтения и визуального рендера обеих КР в этом проходе не заявляется.

Правила сохранности в `frontend/src/clinicalLabels.ts`:

- Поддержаны только два точных кода. F32.11 не получает пояснение F32.1; составная/свободная запись остаётся исходной. F43.1 в этот ограниченный словарь пока не включён.
- Перевод простой строки применяется только к явно известному источнику MIS/synthetic_mis_json и шаблону «название + число + mg». Цифры не преобразуются и не округляются; другие единицы, формы выпуска, комбинации и инструкции не разбираются догадками.
- Личный текст пациента и неизвестный источник не переводятся. Исходное назначение врача доступно в раскрываемом блоке.
- Для Prazosin/Bupropion проверенный источник написания в этом проходе не получен. Они остаются исходными строками; их регистрация/применимость не считается проверенной. Полное покрытие UI-4 и клинического каталога C07/C08 остаётся открытым до соответствующего комплекта B01.

Проверки: точный код/чужой подкод/свободный текст; сохранность дозы и личной записи; неизвестное имя, другая единица, форма/схема/комбинация. Ссылки в интерфейсе ведут к общим документам и не содержат сведений пациента.
