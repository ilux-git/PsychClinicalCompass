# Конструктор опросов: начальные наблюдения

25.10.2026. Это начальный аудит текущего поведения, а не отчёт о завершённом исправлении.

На изолированном стенде с синтетическими данными открыт редактируемый шаблон об удобстве приложения. При контролируемом отказе сохранения на ширине 375 px показаны два сообщения об одной ошибке: общее уведомление и сообщение над конструктором. Введённые название и вопросы сохранились; фокус не переведён к ошибке внутри редактора. [Наблюдение](before.json), [кадр](before-save-error-mobile.jpg).

Новая анкета, версия, назначение и ответ пациента в этом аудите не сохранены; баллы не начислялись. Медицинские тексты и правила не менялись. После проверки режим отказа отключён.

Следующий независимый шаг: локальное сообщение об ошибке с фокусом в редакторе, проверка ручного повтора без потери ввода и отдельная проверка частичного успеха «черновик сохранён, публикация не удалась». Реализация и итоговая приёмка этих изменений пока отсутствуют.
