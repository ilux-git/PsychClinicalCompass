# Telegram Mini App · 27.10.2026

Источник: предоставленные пользователем `PsychClinicalCompass_Telegram_Mini_App_TZ.md`, `UI Design 2.txt` и `Лимбус_Финал.png`. Бот подтверждён методом getMe: `@LimbusMed_bot`; секрет хранится только в исключённом из Git `work/dev.env`. VPS ещё не приобретён. Собственный платный домен не обязателен; для живого теста нужен доступный HTTPS-адрес.

## Порядок работы

1. Проверка подписанных initData на сервере, постоянная привязка существующего аккаунта, отдельные вход/замена/отвязка, блокировка входа выключенного аккаунта. Сохранить ограничения попыток, аудит и проверку связи врача с пациентом. Проверить гонки и отзыв уже созданных Telegram-сессий.
2. `/tg` с общими ролевыми компонентами и API, вход без хранения пароля или Telegram initData, настройки привязки, Telegram BackButton, безопасные области, светлая/тёмная тема и переход в веб-версию. Веб-вход и десктопные функции сохраняются.
3. Применить отдельные визуальные правки: новый фон входа, русские демо-имена, заголовки таблицы, соединённый маршрут, разные изображения дней и спокойный фон.
4. Миграция без сброса данных, серверные и компонентные проверки, production-сборка и браузерная проверка доступных ролей/размеров; инструкции BotFather/Compose/HTTPS и очередь оставшихся вопросов.

## Границы

- Mini App не включает автоматически доставку сообщений ботом. Вход Mini App и прежний webhook включаются разными настройками. Журнал переписки доступен через существующий API; статус симулятора остаётся честным.
- Только пациент и врач могут привязать Telegram. Роль определяется учётной записью, а не полем клиента или профилем Telegram.
- Проверенный Telegram user ID не подменяет подтверждение личного чата или разрешение писать пользователю. Новая привязка не придумывает chat ID.
- Техническое окно допустимости initData по умолчанию 300 секунд, настраиваемое; переподключение при истечении через повторное открытие приложения.
- После локальной реализации пользователь разрешил временный публичный HTTPS; туннель и меню подключены, readback подтверждён. Настоящая пользовательская сессия на телефоне остаётся в живой приёмке.
- Клинические правила, данные и права администратора не расширяются.

## Что остаётся внешним

- Стабильный HTTPS-адрес для финального стенда и сервер AEZA; временный туннель возможен для синтетического теста.
- Финальная проверка в Telegram на телефоне пользователя. Локальные подписанные тесты не выдаются за реальный вход из Telegram.
- Конфигурация стандартного меню уже изменена по разрешению пользователя; повторного выбора запуска не требуется. Webhook и доставка сообщений не включались.
