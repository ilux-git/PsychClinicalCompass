## Основные маршруты

| Роль | Последовательность | Наблюдаемый результат |
|---|---|---|
| Врач | Вход → свои пациенты → конкретный ответ/событие → следующее действие → доска задач → отдельная проверка | Источник, исполнитель, сроки, действие и результат не смешиваются. Клинические задачи остаются лечащему врачу |
| Пациент | Мой день → назначенный опрос / дневник / расписание → сохранённая история → маршрут и скидки | Следующий шаг виден сразу; добровольные действия и спокойный режим доступны без штрафов |
| Пациент с затруднением | Диалог → явный флаг «Мне нужна поддержка» → сообщение → статус запроса → ответ врача | Событие создаётся из явного выбора пациента, без классификации ключевых слов или чтения личного дневника |
| Врач по обращению | Очередь → карточка, вкладка «События» → задача + необязательный ответ | Одна атомарная команда сохраняет задачу, ответ, принятие, аудит и при необходимости outbox. Повтор команды не создаёт дубликаты |
| Координатор | Свои организационные задачи → взять в работу → описать действие → выполнено | Исходное клиническое сообщение, приватная заметка и комментарий проверки врача недоступны |
| Администратор / аналитик | Охват и опросы → барьеры → действия и исходы → источники и защита | Агрегаты с общей политикой групп; без ФИО, карточек, цитат и произвольных фильтров |

Обучение каждой роли проходит по настоящим разделам. Его можно закрыть и повторно открыть. Локальная отметка обучения привязана к пользователю/роли/версии; она не отправляет ответы, не подтверждает события и не начисляет баллы.

## CRM и карточка

- Пациенты — первый экран врача, в том числе после восстановления сессии. Поиск буквальный, список разбит на страницы. Показаны фактические незакрытые события, задачи и дата последнего измерения.
- Доска «Назначено → В работе → Действие выполнено»: поиск, страницы каждого столбца, явные кнопки, отдельная проверка результата. Версия защищает от затирания конкурентного изменения; повтор неизменного действия не дублирует аудит.
- Карточка разделена на обратную связь, план/задачи, события, лекарства, диалог и состояние/МИС. Очередь открывает сразу события. Из связанного действия виден номер задачи после обновления страницы.
- Завершение требует описания выполненного действия. Проверка врача: устранено / сохраняется / неизвестно. Выполненная задача не означает оказанную помощь или завершённое лечение.
- При исходе «отказался» врач может классифицировать сообщённую причину: деньги, время, семья, воспринимаемая польза, неприятные ощущения со слов пациента, другое, отказ сообщать или неизвестно. Комментарий остаётся в карточке; администратор получает только защищённые категории. Прежняя история не переинтерпретируется автоматически.

## Мотивация

Баллы за участие сохраняют тариф `demo-effort-v1`: ответы, ведение лекарственного расписания и дневник; дневные лимиты UTC. Нет начисления за «хорошие» симптомы, число лекарств, sharing или просмотр обучения.

Три вида: карта маленьких шагов, ритм за 7 UTC-дней, спокойный режим. Врач рекомендует вид; пациент выбирает свой. Это предпочтение интерфейса, без определения психотипа. Игровые отметки открываются при накоплении 0/25/50/100/250 баллов и не являются этапами выздоровления. Обмен не откатывает карту.

Тестовый каталог `demo-visit-discounts-v1`: 100 баллов → 5%, 250 → 10%. Просмотр предложения → подтверждение → резерв баллов → DEMO-код → возможная отмена с освобождением баллов. Защищены недостаточный баланс, одновременные запросы, повторы, устаревший каталог и откат аудита. **Код нельзя использовать в реальной клинике:** цена, оплата и МИС не меняются; реальный обмен выключен.

Для пациента 2 seed создаёт отдельную учебную историю дневника и соответствующих начислений: 34 дня × 3 = 102 балла. Старые ответы и события не пересчитываются задним числом. Seed повторяемый; записи помечены синтетическими, личный дневник не публикуется врачу.

## Вычисляемые показатели

| Показатель | Формула / границы |
|---|---|
| Сообщённые причины отказов | Только последняя запись врача со статусом «отказался», одна текущая причина на пациента. Неопределённая причина и отказ сообщать остаются отдельными |
| Принятие запросов поддержки | Число обращений с явным временем принятия / все явно созданные обращения, включая ещё не попавшие в очередь |
| Следующий шаг по обращению | Количество обращений, для которых команда врача создала связанную задачу; число задач не подставляется вместо числа обращений |
| Связанный ответ | Обращения с явно связанным ответом команды врача. Обычное последующее сообщение не приписывается автоматически |
| Время принятия / ответа | Медианы измеренных неотрицательных интервалов от создания сообщения до принятия / первого связанного ответа; отдельно число интервалов. Неизвестные значения не становятся нулём |
| Текущее ожидание | Максимальный возраст ещё не принятых обращений; без ожидающих — «нет измеренного интервала». Это не просрочка согласованного SLA |
| Исходы / действия / проверки / окна визитов / лекарственные отметки | Сохранены прежние определения и зрелые знаменатели из [MVP_WORKFLOWS](MVP_WORKFLOWS.md) |

Графики используют реальные даты, отдельные шкалы/версии и неизвестные значения. На телефоне SVG перестраивается по ширине; единичная точка не выдаётся за тренд. Администратор получает новые показатели только после проверки различных пациентов и дополнений групп; 12 обращений одного пациента не проходят порог 2.
