## Основные маршруты

| Роль | Последовательность | Наблюдаемый результат |
|---|---|---|
| Врач | Вход → свои пациенты → конкретный ответ/событие → следующее действие → доска задач → отдельная проверка | Источник, исполнитель, сроки, действие и результат не смешиваются. Клинические задачи остаются лечащему врачу |
| Пациент | Мой день → назначенный опрос / дневник / расписание → сохранённая история → маршрут и скидки | Следующий шаг виден сразу; добровольные действия и спокойный режим доступны без штрафов |
| Пациент с затруднением | Диалог → явный флаг «Мне нужна поддержка» → сообщение → статус запроса → ответ врача | Событие создаётся из явного выбора пациента, без классификации ключевых слов или чтения личного дневника |
| Врач по обращению | Очередь → карточка, вкладка «События» → задача + необязательный ответ | Одна атомарная команда сохраняет задачу, ответ, принятие, аудит и при необходимости outbox. Повтор команды не создаёт дубликаты |
| Координатор | Свои организационные задачи → взять в работу → описать действие → выполнено | Исходное клиническое сообщение, приватная заметка и комментарий проверки врача недоступны |
| Администратор / аналитик | Охват и опросы → барьеры → действия и исходы → источники и защита | Агрегаты с общей политикой групп; без ФИО, карточек, цитат и произвольных фильтров |

Обучение каждой роли проходит по настоящим разделам. Его можно закрыть и повторно открыть. Локальная отметка обучения привязана к пользователю/роли/версии; она не отправляет ответы, не подтверждает события и не начисляет баллы.

## CRM и карточка

- Пациенты — первый экран врача, в том числе после восстановления сессии. Поиск буквальный, список разбит на страницы. Показаны фактические незакрытые события, задачи и дата последнего измерения.
- Доска «Назначено → В работе → Действие выполнено»: поиск, страницы каждого столбца, явные кнопки, отдельная проверка результата. Версия защищает от затирания конкурентного изменения; повтор неизменного действия не дублирует аудит.
- Карточка разделена на обратную связь, план/задачи, события, лекарства, диалог и состояние/МИС. Очередь открывает сразу события. Из связанного действия виден номер задачи после обновления страницы.
- Завершение требует описания выполненного действия. Проверка врача: устранено / сохраняется / неизвестно. Выполненная задача не означает оказанную помощь или завершённое лечение.

Комментарий остаётся в карточке; администратор получает только защищённые категории. Прежняя история не переинтерпретируется автоматически.
