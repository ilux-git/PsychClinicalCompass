## Применение уточнения врача

- Исходные F53.0/F41.1/F43.2 — ранее установленные врачом диагнозы; приложение не ставит их заново.
- Новая интоксикация не устанавливается системой. Её вправе установить врач после сообщения пациента о явлениях и собственной оценки. Исходный сценарий сам по себе не добавляет этот диагноз.
- Записанная врачом терапия, запланированная терапия и предположение системы имеют отдельные подписи. Одобрение гипотезы не переписывает назначения и не считается записью в МИС.
- Креатинин без единиц не используется для расчёта СКФ. Одного значения недостаточно для автоматического диагноза ХБП и её стадии.

## EPDS: русскоязычные основания

1. [Шаманина М.В., Мазо Г.Э., 2015, с. 74–82](https://psychiatr.ru/files/magazines/2015_03_obozr_846.pdf#page=76). Апробация у 230 женщин Санкт-Петербурга со второй недели до года после родов, с обследованием психиатром. Это российская клиническая публикация; наличие исследования не означает универсальной категории тяжести для любой суммы.
2. [Якупова В.А., 2018, DOI 10.15405/epsbs.2018.07.89](https://www.europeanproceedings.com/article/10.15405/epsbs.2018.07.89). Русскоязычная версия изучена у 151 матери детей 1–11 месяцев; α=0,838 характеризует внутреннюю согласованность, корреляция с Беком r=0,798. Пороговые выводы относятся к исследованной выборке, а не заменяют диагноз врача.
3. [Рубрикатор Минздрава: КР 799_1](https://cr.minzdrav.gov.ru/view-cr/799_1), «Нормальный послеродовый период», 2024, приложение Г2. Карточка официального источника найдена, однако её полный текст на этой проверке не загрузился. Точную редакцию бланка и её соответствие конкретной адаптации ещё требуется сверить; не объявляем такую сверку выполненной.

Для цифрового бланка есть отдельный вопрос о правах. Старый [справочник RCPsych](https://www.rcpsych.ac.uk/docs/default-source/members/devolved-nations/rcpsych-in-scotland/faculties/scotland-faculties-addictions-national-institute-for-mental-health-in-england-outcomes-compendium.pdf) описывает воспроизведение с атрибуцией, а [документация исследовательской системы CamCOPS](https://camcops.readthedocs.io/en/latest/tasks/epds.html) сообщает об ограничении онлайн-перепубликации по разъяснению правообладателя. Актуальное разрешение для нашего цифрового размещения не получено. Полный текст десяти вопросов не включён в продукт как якобы свободный.

Суммы **18 и 9** уже отображаются отдельной переданной историей, без придуманных ответов по пунктам, маркировки адаптацией 2015/2018 и категории «тяжёлая/лёгкая». Они не объединены с новой канонической шкалой. Отсутствие исходных ответов, в том числе по пункту самоповреждения, остаётся неизвестным, а не отрицательным ответом. Снижение суммы не приписывается эффекту конкретного препарата автоматически.

## Технические границы

Компас хранит новые аккаунты, исходные эпизоды, сообщения, outbox, разбор и аудит в своей БД. Три профиля МИС читаются из согласованного JSON-контура; запись в таблицы МИС отсутствует. Администратор не получает карточки и клинические гипотезы. Резервный координатор получает организационное уведомление по ID без цитаты, диагноза и списка лекарств. Живая Telegram-доставка подтверждается только фактическим ответом внешнего API.

Проверки и состояние развёртывания фиксируются в [актуальной приёмке](VERIFICATION.md), вопросы, зависящие от команды/клиники/правообладателя, — в [очереди](OPEN_QUESTIONS.md).
