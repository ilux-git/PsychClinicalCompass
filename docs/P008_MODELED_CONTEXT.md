# P008: отдельный смоделированный контекст для показа

Пользователь разрешил дополнить гипотетическую историю. Это **предлагаемая модель для согласования врачом**, а не извлечённые из исходного файла сведения и не новое назначение приложения. Исходный `сценарии.txt`, диагноз F53.0, временные срезы и история EPDS 18 → 9 сохраняются отдельно.

Для примера, в котором рассматривается зарегистрированное показание Авиандра, используется такой контекст:

| Сведение | Предлагаемое дополнение |
|---|---|
| Состояние | Кроме ранее установленного послеродового расстройства, врач отдельно установил генерализованное тревожное расстройство F41.1. Этот диагноз не выводится из EPDS или сообщения пациента. |
| Репродуктивный контекст | Совершеннолетняя пациентка; беременность исключена врачом, грудное вскармливание завершено. Это условия модели, отсутствующие в исходном файле. |
| Противопоказания | У врача есть актуальные анализы и заключение об отсутствии противопоказаний, включая нарушение функции почек по инструкции. Приложение не заполняет отсутствующие анализы нормальными значениями. |
| Исходная совместная схема | Остаётся поводом для разбора возможного взаимодействия. Дополнение не объявляет комбинацию с эсциталопрамом безопасной. |
| Последний срез | Согласно исходному сценарию, на 84-й день прежний препарат отменён врачом. После проверки перехода и сопутствующих препаратов врач рассматривает текущую терапию тревожного расстройства; интервал отмены и новая доза здесь не придумываются. |
| Наблюдаемый результат | Сообщение пациентки и значения шкалы — отдельные наблюдения. Они не доказывают эффект конкретного препарата или его применимость при послеродовой депрессии. |

Основание границ модели — [ОХЛП производителя от 16.07.2026](https://disk.360.yandex.ru/i/n-l5OQc0Fbsojw), размещённая на [странице для специалистов](https://aviandr.ru/medic). Файл не подтверждает показание «послеродовая депрессия»; показание в этой модели связано с отдельно установленным тревожным расстройством. Соответствие текущей редакции ГРЛС остаётся на проверке, как указано в [сценариях](AVIANDR_SCENARIOS.md).

В рабочие записи МИС и неизменяемые исходные эпизоды эти дополнения не внесены. При показе разделяются исходные факты, предлагаемый контекст и решение врача; постановка нового диагноза системой не имитируется.
