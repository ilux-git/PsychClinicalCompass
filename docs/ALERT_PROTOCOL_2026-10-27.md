## Согласованный пациентский блок

При критическом сообщении: **«Позвоните112 сейчас. Не ждите ответа в чате»**. В обычном чате блок «Экстренная помощь» свёрнут и содержит условную инструкцию при опасности для жизни.

Предлагаемые подписи двух кнопок: **«112 · Экстренная служба»**, **«103 · Скорая помощь»**. Нажатие только открывает набор номера на устройстве; приложение не выполняет автозвонок, не отправляет сведения пациента и не подтверждает вызов службы. Блок доступен сразу, без ожидания пяти минут.

**Разрешение получено:** после остановки автоматической проверкой пользователь отдельно разрешил ручные кнопки 112/103 и потребовал простого пояснения для человека в критическом состоянии. Приложение показывает, как подтвердить звонок и назвать местоположение; автоматических звонков или передачи данных нет. После CRITICAL сведения доступны сразу, также при ошибке обновления истории после успешной отправки. Зарубежный телефон доверия не подставляется вместо согласованного контакта для РФ. Фактический звонок при проверках не выполняется.

## Проверка и остаток реализации

Проверяются: границы числовых критериев, различие HIGH/CRITICAL, отрицания и цитаты, авторство/связь с пациентом, атомарность и повтор, приоритетная пагинация, передача только ID координатору, невозможность закрыть событие одним принятием.

Отдельный остаток: планировщик лекарственных напоминаний, настраиваемое окно врача default7 дней, правило недели без отметок, три явных дня пропуска и три пропущенных цикла опросов. Наличие согласованных правил не объявляет эти функции реализованными.
