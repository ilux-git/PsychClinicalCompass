## Сценарии приёмки

- Пациент: главный экран → назначенный опрос → сохранить часть → вернуться → продолжить → отправить → история. До отправки ответ не доступен врачу, не участвует в аналитике и не даёт баллов.
- Врач: найти пациента → прочитать источник → выбрать действие/исполнителя → сохранить → увидеть задачу → проверить результат. Общие события доступны из постоянной шапки; карточка открывается на нужном разделе.
- Аналитик: выбрать предмет сводки → прочитать величину и знаменатель → открыть пояснение источника. Индивидуальные данные остаются закрыты.
- Координатор: своя доска → принять → описать выполненное действие. Нет клинического доступа.

Целевые размеры: 375×812, 768×1024, 1440×900. Проверяются реальная ширина DOM, отсутствие горизонтального переполнения, читаемость, фокус и клавиатура, длинные подписи, уменьшенное движение. Начальная загрузка сохраняет структуру; пустые и частичные данные не становятся нулями; ошибка предлагает повтор; успех имеет следующий шаг; недоступный объект не раскрывает содержимое. Непроверенное состояние фиксируется как непроверенное.
