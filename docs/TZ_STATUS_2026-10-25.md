# Статус требований на 25.10.2026

Уточнение: [полная буквальная сверка всех11 обязательных условий](MANDATORY_REQUIREMENTS_STATUS_2026-10-25.md) имеет приоритет над сокращениями слайда ниже. В частности, пункт2 остаётся частичным до выполнения требований по ЭМК и границам обработки/хранения; пункт9 проверяется отдельно.

Сверка с показанным слайдом после последних изменений. Основание: текущий код, [матрица обязательных условий](REVISION_PLAN_2026-10-25.md#2-что-подтвердилось-в-аудите), [проверка источников](CLINICAL_SOURCE_REVIEW.md), [последние проверки](evidence/control-map-2026-10-25/report.json). В слайд нужно добавить отдельно:

- **Прямая передача в ЭМК — не реализована.** МИС остаётся источником только для чтения; ответы сохраняются в Compass. Привязка к врачу не закрывает это обязательное условие.
- **1000 одновременных пользователей / максимум 500 мс — не подтверждено.** Новые функциональные тесты не являются таким нагрузочным испытанием; [результаты нагрузки](LOAD_TESTING.md) сохраняют свои ограничения.

Правую колонку можно обновить такими фактическими формулировками:

1. Рабочий день врача и точные выборки задач: выполнение, проверка, проверенные результаты, прошедшие сроки.
2. Связанные ответы, действия и отдельная проверка результата; приватные заметки врача.
3. Конструктор, публикация версий и назначение врачебных опросов.
4. Числовые demo-результаты PHQ-9/GAD-7 и сопоставимая история состояния.
5. Чат с запросом поддержки, дневник и лекарственные самоотчёты.
6. Агрегированная аналитика клиники с отдельным учётом неизвестных исходов.
7. Баллы, морская карта участия, пейзажный календарь и DEMO-скидки.

Последняя проверка: **156 backend / 83 frontend**, TypeScript/Vite и шесть дополнительных проверок после двух статичных подписей; нативные сценарии четырёх ролей и мобильная ширина. Эти числа относятся к инженерной проверке, а не к проценту выполненных клинических условий.

Ближайшие изменения интерфейса продолжаются независимо. Для закрытия обязательных клинических пробелов остаются конкретные решения [B01–B07](REVISION_PLAN_2026-10-25.md#7-блокирующие-вопросы-и-что-продолжать-без-ответа); согласованные ранее роли, баллы, симулятор и нагрузочные требования повторно не запрашиваются.
