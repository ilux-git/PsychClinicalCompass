Task 2: Core (Auth & Patients).
Create the base SQLAlchemy models and structure for the "Access" and "Patients" modules.

What to do:

User (id, role [doctor/patient/admin], hashed_password, created_at).

Patient (id, mis_id, full_name, doctor_id).

PatientMapping (mapping table for MIS and Compass identifiers).

MIS DB Models (app/modules/integration/mis_models.py):

MIS_Patient (id, full_name, diagnoses, prescriptions) — read-only.

Security (app/core/security.py):

Stubs for JWT token creation and password hashing.

Dependencies (app/api/deps.py):

get_current_user function (extracts user from token).

require_role(roles: list) function (checks RBAC, raises 403 if the role is not allowed).

Output the code for models, security, and deps. Do not write routers yet, only the foundation for them.
